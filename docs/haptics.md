# Вибрация (тактильный отклик)

Звука в прототипе нет: вся «сочность» — вибрация. Одна точка вызова на все события —
`Haptics.haptic("<event_id>")`; что именно произойдёт, решает таблица профилей.

- Автолоад: `scripts/autoload/haptics.gd` (`Haptics`), по порядку в `[autoload]` идёт после `Iap` и до `Meta`.
- Таблица рисунков: `scripts/data/haptics.gd` (только данные, статика).
- Документ дизайна: `docs/GDD.md` §15.

## API

| Вызов | Что делает |
| --- | --- |
| `Haptics.haptic(event_id)` | Проиграть профиль события. Нет профиля → `push_warning("[Haptics] нет профиля <id>")` один раз на id, игры нет. |
| `Haptics.buzz(ms, amplitude = 0.5)` | Разовая вибрация заданной длительности и силы (для отладочных кнопок). |
| `Haptics.mute_for_ads(true / false)` | Глушит вибрацию на время rewarded- и interstitial-рекламы (GDD §15 — обязательно). При `true` также сбрасывает текущий рисунок. |
| `Haptics.set_enabled(value)` | Вкл/выкл вибрацию, пишет в сохранение `haptics_enabled`. |
| `Haptics.has(event_id)` | Есть ли профиль для события. |

Правила поведения:

- вибрация не играет, если выключена в настройках, заглушена рекламой или платформа не мобильная (`OS.has_feature("mobile")`);
- одинаковые события троттлятся: не чаще `THROTTLE_MS = 40` мс (частые тапы по полю не превращаются в непрерывную дрожь);
- одновременно играет только один рисунок: новый запрос во время игры предыдущего отбрасывается;
- рисунок прерывается сразу, если вибрацию выключили или включили рекламу.

## Таблица профилей

`pattern` — массив в миллисекундах: чётные индексы — жужжание, нечётные — пауза
(`[18, 60, 18]` = два коротких жужжания с паузой). `amplitude` — сила 0.0..1.0
(Android учитывает её, iOS даёт системный отклик, поэтому рисунки там воспринимаются
как серия коротких вибраций).

Сила выведена из смысла события: лёгкое подтверждение ≈ 0.35, обычное действие 0.6,
значимое событие 0.9–1.0, провалы и «мало энергии» — повторяющийся рисунок.

| Событие | Где вызывается | pattern (мс) | amplitude |
| --- | --- | --- | --- |
| `button` | Обычные кнопки интерфейса (попапы, покупка декора, расстановка) | `[12]` | 0.35 |
| `button_alt` | Альтернативные/технические кнопки (кнопки техспайка в настройках) | `[16]` | 0.45 |
| `tap` | Тап по предмету на поле (продажа) | `[10]` | 0.35 |
| `generator_tap` | Тап по генератору | `[14]` | 0.4 |
| `merge` | Обычное слияние | `[20]` | 0.6 |
| `merge_high` | Слияние до высокого уровня | `[32]` | 0.9 |
| `merge_fail` | Слияние невозможно | `[18, 60, 18]` | 0.6 |
| `error` | Ошибка/неудачное действие | `[20, 60, 20]` | 0.6 |
| `out_of_energy` | Закончилась энергия | `[14, 50, 14, 50, 14]` | 0.5 |
| `coins` | Начислены монеты | `[14]` | 0.35 |
| `gem` | Выпал/начислен гем | `[12, 40, 12]` | 0.5 |
| `order_done` | Заказ выполнен | `[18, 45, 26]` | 0.6 |
| `level_up` | Новый уровень кофейни | `[35, 60, 35]` | 0.9 |
| `chest` | Открыт котовый сундук | `[40, 70, 40, 70, 90]` | 1.0 |
| `cat_unlock` | Открыт новый кот | `[26, 50, 40]` | 0.9 |
| `daily` | Ежедневная награда получена | `[20, 55, 30]` | 0.65 |
| `purchase` | Успешная покупка (в т.ч. заглушка Iap) | `[30, 60, 70]` | 0.9 |
| `rewarded_start` | Показ rewarded-рекламы начался | `[14]` | 0.35 |
| `rewarded_done` | Награда за rewarded получена | `[20, 50, 30]` | 0.65 |
| `order` | Зарезервировано (вызовов пока нет) | `[14]` | 0.35 |
| `xp` | Зарезервировано (вызовов пока нет) | `[12]` | 0.35 |

Список id, которые реально зовёт игра, — `DATA.used_ids()`; самопроверка при запуске
(строка `[selftest] haptics: OK` в логе) сверяет, что каждый из них есть в таблице,
`amplitude` в диапазоне 0..1 и `pattern` не пуст.

## Настройки и сохранение

- Тумблер «📳 Вибрация» — в попапе настроек (`scripts/ui/settings_popup.gd`), состояние читает `Haptics.enabled`.
- Ключ сейва: `haptics_enabled`. Старый ключ `audio_haptics` (от удалённого звука) читается как фолбек, чтобы у игроков с прежним сейвом выбор сохранился.
- Флаги удалённого звука `audio_music`, `audio_sfx` больше не используются.

## Как добавить событие

1. Дописать профиль в `PROFILES` (`scripts/data/haptics.gd`) — подобрать силу и рисунок по таблице выше.
2. Если событие появится в игре — добавить его id в `used_ids()`, чтобы самопроверка за него отвечала.
3. В игре вызвать `Haptics.haptic("<id>")`.
