# Презентация продукта — Sweetie Cat's Cafe

Питч-дек на 16 слайдов: УТП, механики, сравнение с конкурентами, юнит-экономика,
метрики и критерии успешного софт-лонча.

## Как открыть

Открыть `index.html` в любом браузере (интернет не нужен — внешних шрифтов,
скриптов и картинок нет).

```bash
open docs/presentation/index.html
```

Управление: `←` / `→` / `Space` — навигация, `Home` / `End` — начало и конец,
`P` — печать в PDF (по слайду на страницу), клик по правой/левой половине слайда,
свайп на тач-устройстве. Номер слайда хранится в адресе (`index.html#7`).

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | все слайды, текст и данные |
| `styles.css` | оформление, сетки, печатная версия |
| `deck.js` | масштабирование под экран, навигация, точки, свайп |

## Откуда числа

- **Механики и баланс** — `docs/GDD.md` (§25 — экономика) и `scripts/autoload/config.gd`
  (в деке указаны фактические значения прототипа: поле 5×6, заряды 6/9/12 и т. д.).
- **Цепочки, коты, декор** — `scripts/data/chains.gd`, `scripts/data/meta.gd`
  (22 предмета цепочек, 12 котов, 27 предметов декора).
- **События аналитики** — `docs/analytics.md` §10 (32 события в реестре).
- **Юнит-экономика** — модель на допущениях из `docs/GDD.md` §25.10–25.11: eCPM,
  показы rewarded/interstitial, конверсия в платящих, ARPPU и кривая удержания
  `R(d) = 42% · d^−0.53` (подогнана под D1 42% / D7 15% / D30 7%).
  LTV считается как сумма активных дней × ARPDAU: 3.8 дня за 30, 9.7 за 180, 13.8 за 365.
- **Сравнение с конкурентами** — качественная оценка по публичным обзорам
  (Travel Town, Merge Mansion, Gossip Harbor, Love & Pies, EverMerge). Внутренних
  цифр конкурентов нет, это указано на слайде.

Числа живут в тексте слайдов. Если меняется баланс в `Config` — правится
соответствующий слайд (`index.html`), отдельного источника данных нет.
